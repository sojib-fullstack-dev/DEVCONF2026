# DevConf 2026 — Event Landing Page

A responsive landing page for DevConf 2026, a fictional 3-day developer conference. Built as an assignment for Programming Hero, Batch 14, focused on structuring a real-world event site with semantic HTML and pure CSS — no frameworks.

🔗 **Live Demo:** https://sojib-fullstack-dev.github.io/DEVCONF2026/

## 🛠️ Built With

* **HTML5** — semantic markup
* **CSS3** — Flexbox & Grid for layout, no CSS frameworks
* **Font Awesome** — icons
* **Google Fonts** — Inter & Arimo

## ✨ Features

* Sticky navbar with logo, nav links, and a "Register Now" CTA
* Hero section with dark-overlay background image and headline
* Speakers section showcasing 4 speakers with photo, category, name, and role
* Pricing section with 3 tiered plans (Standard, Pro, Team) and feature comparisons
* 3-day schedule/agenda section — sessions organized by day and by track (Track A/B/C), each with start–end times, so simultaneous sessions across tracks are easy to scan
* Footer with logo and social links

## 🤖 AI Collaboration Note

Most of this project was hand-coded, but the schedule/agenda section was built with AI assistance as part of practicing prompt engineering — a core requirement of this assignment. I described the existing sections, the constraints (semantic HTML, no advanced CSS, Grid/Flexbox only, split into HTML and CSS files), and the data to include (venue, 4 speakers, 3 days, session times, tracks), then refined the AI's output to fit the rest of the page.

## 📦 Dependencies

None — pure HTML and CSS. Font Awesome and Google Fonts are loaded via CDN links in `index.html`, no local installation needed.
